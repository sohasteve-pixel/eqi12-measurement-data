EQi12 USB-C数据与转接头性能定位
日期：2026-07-12
设备：同一EAGET USB SSD、同一原装USB-A线

组合A：EQi12 USB-C -> USB-C转USB-A转接头 -> SSD原USB-A线
- 4GiB完整读取并SHA256：539.10MiB/s，校验一致。
- 4GiB持续写入：39.23MiB/s。
- 空闲后1GiB复测：写入调用39.66MiB/s，强制落盘0.118秒，总体39.48MiB/s。

组合B：EQi12前置USB-A -> SSD原USB-A线
- 同脚本1GiB对照：写入调用298.91MiB/s，强制落盘0.118秒，总体288.97MiB/s。

结论：
1. USB-C端口数据链路可用，读取超过500MiB/s且SHA256一致。
2. SSD本身当前可恢复约299MiB/s写入，因此不是SSD垃圾回收导致39MiB/s。
3. USB-C转USB-A转接头/组合存在明显的单向写入性能异常；不代表EQi12原生USB-C口本体写入能力。
4. 需要原生USB-C高速存储设备或另一只合格的USB 3.x C转A转接头，才能给USB-C原生写入性能作最终判定。
