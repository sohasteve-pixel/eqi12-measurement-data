Hardware acceleration boundary:
- WSL Ubuntu exposes /dev/dxg.
- Docker Desktop containers expose neither /dev/dri nor /dev/dxg on this system.
- Therefore this Docker Jellyfin deployment cannot currently validate Intel Quick Sync hardware transcoding.
- The result above is a software-transcode baseline only and must not be described as hardware transcoding.
- Hardware-transcode validation requires Windows-native Jellyfin or a separately verified GPU-passthrough configuration, plus Dashboard/log evidence.
